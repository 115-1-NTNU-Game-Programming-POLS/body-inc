# 程式繪製的草稿素材

本資料夾的圖全部由 `tools/art/draw_drafts.py` 產生，屬於灰盒期草稿，用來讓關卡與程式組員先拼房間、測換色流程。江兆耘的正式圖完成後，依同一個檔名或同一個圖塊格位覆蓋即可，地圖不需重擺。改圖請改腳本後重跑，不要直接改 PNG。

| 路徑 | 內容 |
| --- | --- |
| `fx/` | 紙屑 4 種、命中墨點 3 格、腺苷棉絮 3 種、汗滴、白煙 4 格、飛出的領帶 |
| `emote/` | 營運長頭上表情圖示 6 種（…、？、!?、汗滴、怒筋、音符），16 × 16 |
| `tiles/tiles-greybox-struct.png` | 共用骨架的索引灰階版，8 欄版位；格位編號見同名 `.slots.json` 與 `-labeled-3x.png`。此版位是提案，需與江兆耘定稿後才凍結 |
| `tiles/tiles-<world>-struct.png` | 骨架依 `art-src/palette/worlds.json` 換色後的六個世界版本 |
| `tiles/` 其他 | 大廳大理石方格、考場地磚、肝工廠六角磚、倉庫安全線、輸送帶（3 種密度 × 4 方向 × 4 格） |
| `props/` | 方箱骨架（一般、可推、葡萄糖、乙醛、核心傾印、福利紙箱）與打不動的酒精桶 |
| `preview/` | 拼好的範例房間與小圖總覽，只供檢視 |

方箱的紙箱色 `#D2A86E` 已列入全域色票（`cardboard`）。依美術指南第 7.4 節，遊戲中的方箱類一律使用這裡的方箱骨架，同名的 AI 方箱圖不採用；`tools/art/pack_atlases.py` 會把方箱、特效與表情圖示打包進 `atlas-common`。換色腳本目前是 Python 草稿（`draw_drafts.py` 的 `recolor`），美術指南第 7.3 節指定的 Node 版由程式組員撰寫時可照同一套對應規則。
