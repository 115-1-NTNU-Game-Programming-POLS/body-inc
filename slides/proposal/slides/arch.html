規則和畫面分開，模擬層不開畫面也能測

1　資料層｜JSON

事件卡與連鎖：每條一個檔

食物、部門參數、難度

員工手冊、宿主設定

寫文案的組員不用改程式就能加卡；schema 腳本檢查格式

2　模擬層｜純 JS

sim/，瀏覽器與 Node.js 都能執行

時間推進：逐小時

資源、部門產能、怨氣

事件抽籤與連鎖觸發

狀態標籤＋因果紀錄

倒閉報告：沿因果紀錄追溯

3　呈現層｜p5.js

一個場景一個檔（ui/scenes/）

人體剖面圖、血流粒子

員工立繪：身體、表情、道具三層

對話泡泡、音效與音樂

只讀取模擬層的狀態，不自己改數值

跨局進度存檔

（約 30 秒）這是我們預期的系統架構，分成三層。左邊是資料層，事件卡、食物、手冊都寫成 JSON，寫文案的組員不用改程式就能加卡。中間是模擬層，用純 JavaScript 寫時間推進、部門產能、事件和因果紀錄，倒閉報告就是沿著因果紀錄追溯出來的；它不依賴畫面，所以可以直接在 Node 上跑自動測試，前面的數值模擬就是這樣做的。右邊是 p5.js 的呈現層，只讀取模擬層的狀態來畫，玩家的操作再當成指令送回模擬層。跨局進度存在瀏覽器的 localStorage，整個遊戲部署在 GitHub Pages。
